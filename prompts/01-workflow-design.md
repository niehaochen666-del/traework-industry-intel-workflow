# Prompt 1：工作流顶层设计与任务拆解

## 📌 使用阶段
项目启动与方案确认阶段

## 📥 输入材料
- 目标行业名称
- 已授权信息源清单（类型、数量）
- 目标飞书空间/群组
- 期望的推送节奏

## 💬 Prompt 正文
```
我需要把【目标行业】中已获得合法访问权限的信息源，整理成一条自动化行业情报工作流。核心诉求包括：由 TRAE Work 完成定时增量处理、状态比对去重、四维标签分类、飞书多维表格归档、飞书群卡片推送，以及结构化日报和周报生成。

请先不要直接编写代码，先把任务拆解为可执行的实施步骤，明确每一步的：
1. 输入材料
2. 处理逻辑
3. 预期产出物
4. 所需权限
5. 关键人工检查点

涉及平台规则、版权边界、敏感配置或事实口径的地方请单独列出，输出方案后请停住，等待我确认。
```

## 📤 预期输出
- 系统架构设计说明
- 模块依赖清单
- 数据表字段规划
- 潜在风险提示
- 分步实施计划

## ✅ 人工检查项
- [ ] 信息源授权合规性确认
- [ ] 数据存储范围确认
- [ ] 私有环境访问权限确认
- [ ] 密钥管理机制确认
