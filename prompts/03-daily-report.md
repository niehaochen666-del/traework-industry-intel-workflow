# Prompt 3：生成每日行业情报日报初稿

## 📌 使用阶段
每日日终情报汇总阶段

## 📥 输入材料
- 当日入库结构化资讯
- 目标读者偏好
- 板块结构定义

## 💬 Prompt 正文
```
请读取飞书多维表格【情报沉淀表】中【今日】新增的全部资讯记录，生成一份【目标行业】每日情报日报初稿。

要求：
1）严格按照【市场动态 / 竞品动向 / 政策环境 / 技术观察 / 分析师洞察】五大板块组织；
2）所有事实与数据必须完全源自今日真实入库的记录，每条要点后附带来源媒体与原文链接；
3）若某板块今日无相关资讯则注明"今日暂无相关动态"，严禁虚构或推断；
4）在末尾输出 2-3 条供分析师参考的要点短评；
5）将全文归档至【日报归档表】。

输出后列出需要人工确认的事实清单。
```

## 📤 预期输出
- 格式工整的日报内容
- 多维表格归档记录
- 待核验事实清单

## ✅ 人工检查项
- [ ] 关键数据真实性
- [ ] 原文引用准确性
- [ ] 时间跨度范围
- [ ] 推断结论是否符合客观事实
