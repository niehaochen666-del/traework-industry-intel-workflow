# Prompt 4：生成每周行业趋势研判周报

## 📌 使用阶段
周末全局趋势复盘与研判阶段

## 📥 输入材料
- 本周全量沉淀资讯记录
- 重点关注企业名单
- 核心指标口径

## 💬 Prompt 正文
```
请汇总飞书多维表格【情报沉淀表】中【本周一至周五】新增的全部资讯，生成一份【目标行业】每周趋势研判周报初稿。

要求：
1）在日报结构基础上，重点提炼【数据焦点】与【出海动态】两大专题；
2）提炼本周关键发展态势，所有趋势研判必须明确标注依据了本周哪些具体事件记录，并保留原文链接；
3）输出 2-3 条针对行业参与者的策略启示；
4）把客观事实、模型推断和行动建议分开表达；
5）全文同步归档至【周报归档表】。
```

## 📤 预期输出
- 全局趋势周报内容
- 结构化周报归档文本
- 核心趋势依据清单

## ✅ 人工检查项
- [ ] 跨周期数据统计口径一致性
- [ ] 事件因果推断合理性
- [ ] 策略建议适用范围
