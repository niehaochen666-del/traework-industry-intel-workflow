# Prompt 2：配置定时增量清洗与推送任务

## 📌 使用阶段
信息接入跑通后，配置日常增量流转阶段

## 📥 输入材料
- 已确认的工作流方案
- 字段映射表
- 打标关键词规则
- 飞书 Webhook 环境变量名

## 💬 Prompt 正文
```
请基于已确认的方案，帮我配置一个每天【10:00】自动运行的增量任务：

1）由 TRAE Work 自动处理【已授权信息源】的最新数据，依据【唯一标识字段】与历史状态比对去重；
2）对新增文章进行正文清洗与 Markdown 格式化，按【政策环境 / 技术趋势 / 竞争格局 / 市场动态】规则库匹配最多 2 个业务标签；
3）将清洗后的记录写入飞书多维表格【情报沉淀表】，并组装包含标题、来源、发布时间、标签和原文链接的卡片推送到【飞书群】。

要求：
- 首次运行时仅建立初始基线，不推送历史全量数据
- 所有敏感 Token 均从环境变量读取，不要硬编码
- 执行后输出测试报告并等待我验收
```

## 📤 预期输出
- 增量清洗同步逻辑
- 自动化定时任务配置
- 字段映射逻辑
- 首跑验证报告

## ✅ 人工检查项
- [ ] 增量去重准确性（无漏报与重复入库）
- [ ] 字段映射完整度
- [ ] 卡片链接可点击性
- [ ] 敏感信息是否全部脱敏
