# Prompt 5：通用复杂任务先出方案

## 📌 使用阶段
面临任何复杂、多步骤的业务流程搭建时

## 📥 输入材料
- 业务背景
- 硬性约束条件
- 期望达成的业务产出物

## 💬 Prompt 正文
```
我需要完成【具体复杂任务目标】。请先不要直接开始执行或编写最终代码，先帮我把该任务拆解为一条清晰、可执行的工作流。

每一步请明确写清：
1）输入材料
2）你负责执行的处理动作
3）输出产物
4）我需要进行人工验收的检查点

先输出流程设计方案，待我确认无误后再开始分步推进。
```

## 📤 预期输出
- 结构化的任务拆解计划
- 依赖关系图
- 检查验收清单

## ✅ 人工检查项
- [ ] 步骤完整性
- [ ] 依赖合理性
- [ ] 验收标准明确度
