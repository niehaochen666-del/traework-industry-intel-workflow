## ✨ 这是什么

这是一个面向**行业研究、市场分析、战略规划**岗位的通用 Skill，帮助你把"跟踪行业动态"这件重复劳动，转化为一条 **可执行、可检查、可沉淀** 的自动化工作流。

> ⚠️ **重要声明**：本 Skill **不包含任何采集功能**，仅处理你已经通过合规、授权方式获取的信息源。

## 🎯 核心能力

| 能力 | 说明 |
|:---|:---|
| 🧹 **内容清洗与结构化** | 将零散文章转化为标准化的情报条目 |
| 🏷️ **智能标签分类** | 按你定义的业务维度自动打标 |
| 📊 **飞书多维表格归档** | 自动沉淀为可检索、可筛选的情报知识库 |
| 💬 **飞书群卡片推送** | 每日定时推送增量精选资讯 |
| 📝 **日报/周报自动生成** | 基于沉淀数据自动生成研报初稿 |
