# 完整示例工作流

以新能源商用车行业为例，演示如何从零开始使用「TRAE行业情报工作流」Skill。

## 场景说明
行业：新能源商用车
目标：每天10点推送行业动态，每周五5点生成周报

## 步骤1：启动Skill
打开TRAE Work，直接说：
```
我想使用「TRAE行业情报工作流」Skill 帮我搭建新能源商用车行业情报自动化系统。
请引导我完成配置。
```

## 步骤2：完成引导配置

### 基础配置
| 问题 | 示例回答 |
|:---|:---|
| 行业名称？ | 新能源商用车 |
| 核心标签？ | 政策环境、技术趋势、竞争格局、市场动态、出海动态 |
| 推送时间？ | 上午10点 |
| 日报时间？ | 下午6点 |
| 周报时间？ | 每周五下午5点 |

### 飞书配置
- 飞书群机器人Webhook地址
- 新建多维表格

## 步骤3：测试验证
1. 测试数据导入：3-5篇测试文章
2. 检查清洗效果：正文是否干净、标签是否准确
3. 测试推送卡片
4. 测试日报生成
5. 检查链接

## 步骤4：正式运行
测试没问题后，告诉TRAE Work："测试没问题，可以正式启用了"。

## 日常使用指南
每天：看推送卡片(5分钟) + 核对日报(10-15分钟)
每周五：核对周报(30分钟)
找历史资料：多维表格搜索(几秒钟)

## 进阶技巧
1. 持续优化标签规则
2. 添加自定义板块
3. 调整推送内容数量
