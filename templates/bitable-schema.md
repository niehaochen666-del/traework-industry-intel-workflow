# 飞书多维表格结构建议

## 表1：情报沉淀表（主表）

| 字段名 | 字段类型 | 说明 |
|:---|:---|:---|
| 资讯标题 | 多行文本 | 文章标题 |
| 核心业务标签 | 多选 | 政策环境/技术趋势/竞争格局/市场动态 |
| 信息来源 | 单行文本 | 来源媒体名称 |
| 发布时间 | 日期 | 文章原始发布时间 |
| 核心摘要提取 | 多行文本 | AI提取的100字以内摘要 |
| 研判短评初稿 | 多行文本 | AI生成的初步研判意见 |
| 清洗后正文 | 多行文本 | Markdown格式的干净正文 |
| 原文溯源链接 | 超链接 | 原文地址 |
| 入库时间 | 创建时间 | 自动记录 |
| 是否已推送 | 复选框 | 标记是否已推送 |

## 表2：日报归档表

| 字段名 | 字段类型 | 说明 |
|:---|:---|:---|
| 报告日期 | 日期 | 日报对应日期 |
| 报告标题 | 单行文本 | 自动生成 |
| 市场动态与热点 | 多行文本 | |
| 竞品与战略动向 | 多行文本 | |
| 政策与标准规范 | 多行文本 | |
| 技术与前沿观察 | 多行文本 | |
| 分析师要点洞察 | 多行文本 | |
| 报告全文 | 多行文本 | Markdown格式 |
| 复核状态 | 单选 | 待复核/已复核/已发布 |

## 表3：周报归档表

| 字段名 | 字段类型 | 说明 |
|:---|:---|:---|
| 周次 | 单行文本 | 如：2026年第33周 |
| 报告标题 | 单行文本 | 自动生成 |
| 本周数据焦点 | 多行文本 | |
| 出海与全球化动态 | 多行文本 | |
| 竞争格局演变 | 多行文本 | |
| 技术趋势观察 | 多行文本 | |
| 政策环境变化 | 多行文本 | |
| 策略启示与建议 | 多行文本 | 2-3条策略建议 |
| 报告全文 | 多行文本 | |
| 复核状态 | 单选 | 待复核/已复核/已发布 |
