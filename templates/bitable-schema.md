# 飞书多维表格结构建议

## 表1：情报沉淀表（主表）

| 字段名 | 字段类型 | 说明 |
|:---|:---|:---|
| 资讯标题 | 多行文本 | 文章标题 |
| 核心业务标签 | 多选 | 政策环境/技术趋势/竞争格局/市场动态 |
| 信息来源 | 单行文本 | 来源媒体名称 |
| 发布时间 | 日期 | 文章原始发布时间 |
| 核心摘要提取 | 多行文本 | AI提取的100字以内摘要 |
| 研判短评初稿 | 多行文本 | AI生成的初步研判意见 |
| 清洗后正文 | 多行文本 | Markdown格式的干净正文 |
| 原文溯源链接 | 超链接 | 原文地址 |
| 入库时间 | 创建时间 | 自动记录 |
| 是否已推送 | 复选框 | 标记是否已推送 |

## 一键自动建表

不想手动建表时，把下面这段话直接发给 TRAE Work，它会读取本仓库的 `bitable-schema.json`（机器可读版 schema），通过飞书多维表格 API 自动创建三张表：

```
请读取「TRAE行业情报工作流」Skill 仓库中的 templates/bitable-schema.json，
在我指定的飞书空间创建一个名为【行业情报库】的多维表格，
包含「情报沉淀表」「日报归档表」「周报归档表」三张数据表，
字段名、字段类型与选项值严格按照 schema 创建。
创建完成后返回多维表格链接，并引导我把 App Token 保存到环境变量，
不要在任何正文或截图中明文展示。
```

> ⚠️ 注意：App Token 属于敏感信息，请通过环境变量管理，不要写入公开仓库、正文或截图。
