```

   来源：xxx | 查看原文

🔹 [竞争格局] 文章标题
   来源：xxx | 查看原文
   核心摘要：一句话摘要
今日共录入 N 条结构化情报

```

## 卡片3：每周周报完成通知卡片
推送时间：每周五下午17:00

```
【行业情报周报】本周发展态势与策略研判
AI 生成初稿 - 待分析师复核
周次：2026年第33周

政策占比28% - 技术占比35% - 出海占比18%
点击查看完整周报
```

## 卡片设计原则
1. 信息密度适中：一张卡片3-5条资讯
2. 层级清晰：用emoji、分隔线区分层级
3. 行动明确：每张卡片末尾有跳转链接
4. 状态提示：标注"AI生成初稿 - 待复核"
5. 颜色区分：用不同颜色区分不同类型
