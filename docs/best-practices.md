# 最佳实践指南

## Prompt编写技巧

### 1. 需求要说具体
不好："帮我做个行业资讯系统"
好："帮我搭建新能源商用车行业情报系统，每天10点推送到飞书群，有政策、技术、竞品、市场四个标签，每周五生成周报"

### 2. 遇到问题说现象
不好："系统有bug"
好："今天推送的卡片里，有两篇文章重复了"

### 3. 复杂需求先出方案
```
我想加一个xxx功能，你先帮我想想怎么实现比较好，出个方案我看看。
```

## 配置最佳实践

### 1. 标签不要太多，4-6个最合适
标签太多导致分类不准确、筛选麻烦、维护成本高。

### 2. 关键词规则要持续迭代
用一周把打错标签的文章记下来，统一调整关键词规则，一般迭代2-3次就准确了。

### 3. 敏感信息一定用环境变量
不要把Webhook地址、API Key写在配置文件或截图里。

## 数据质量保障

### 1. 前两周每天花5分钟抽检
检查：有没有重复的、正文是否完整、标签对不对。

### 2. 报告一定要人工复核
AI生成的是初稿，发布前必须：核对数据、确认事实、检查编造信息、补充自己的洞察。

### 3. 定期备份数据
建议每个月导出一次。

## 合规注意事项
1. 只接入合规信息源
2. 不要转发全文，只放摘要和链接
3. 内部使用为主
4. AI内容标注："AI生成初稿，仅供参考"
