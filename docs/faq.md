# 常见问题FAQ

## 入门相关

Q：我完全不懂技术，能用这个Skill吗？
A：完全可以。整个配置过程都是自然语言对话，不需要写任何代码。

Q：这个Skill收费吗？
A：Skill本身是免费开源的，你只需要有TRAE Work环境和飞书账号。

Q：一定要用飞书吗？
A：当前版本主要适配飞书。如果你用其他平台，可以告诉TRAE Work帮你调整。

## 配置相关

Q：信息源怎么添加？
A：直接告诉TRAE Work你要添加什么信息源，它会引导你完成配置。

Q：我可以自定义标签吗？
A：可以。默认提供"政策环境、技术趋势、竞争格局、市场动态"四个标签，你可以增删改。

Q：推送时间可以改吗？
A：可以，直接告诉TRAE Work你想改成几点。

Q：可以推送到多个群吗？
A：可以，配置多个群机器人Webhook就行。

## 使用相关

Q：会不会重复推送同一篇文章？
A：不会，系统有自动去重机制。

Q：AI打标签不准怎么办？
A：正常现象。把打错的文章告诉TRAE Work，让它调整关键词规则，一般迭代2-3次就准确了。

Q：AI生成的报告里有错误怎么办？
A：所以我们设计了人工复核环节。AI是帮你写初稿，最后事实核查还是要靠人。

Q：历史文章可以导入吗？
A：可以，告诉TRAE你要导入历史文章，它会帮你批量处理。

## 安全与合规

Q：我的数据存在哪里？
A：所有数据都存在你自己的飞书多维表格里，数据完全由你掌控。

Q：敏感信息安全吗？
A：所有API Key、Webhook这类敏感信息都通过环境变量管理。

Q：可以用来采集公众号文章吗？
A：本Skill不包含任何采集功能，仅处理你已经通过合规、授权方式获取的信息源。

## 故障排查

Q：今天没有收到推送怎么办？
A：先检查定时任务是否正常运行、Webhook地址有没有过期、今天是不是确实没有新文章。

Q：多维表格里没有新数据怎么办？
A：告诉TRAE Work帮你排查原因。

Q：图片显示不出来怎么办？
A：通常是图片防盗链导致的，TRAE Work会自动处理。

Q：正文出现乱码（编码问题）怎么办？
A：多为信息源页面编码声明缺失导致。把乱码样例发给TRAE Work，让它对该信息源强制按UTF-8/GBK自动探测解码，并在清洗环节加入编码校验。

Q：同一篇文章被重复入库怎么办？
A：先确认唯一标识字段（原文链接或标题+发布时间哈希）是否配置正确；若信息源会更换链接地址，改用"标题+发布时间"组合做去重键。把重复记录样例发给TRAE Work，让它调整去重逻辑并清理重复数据。

Q：卡片里的"查看原文"链接点不开怎么办？
A：检查写入多维表格的链接字段是否为完整URL（含https://），以及卡片JSON模板里的占位符是否被正确替换。可用templates/card-json/里的模板做一次手动发送测试，对比差异。

Q：定时任务到点没有触发怎么办？
A：依次检查：1）TRAE Work的定时任务是否处于启用状态；2）设备/服务是否在线（本地托管时电脑需保持开机）；3）任务时间表达式是否正确。把任务配置截图（脱敏后）发给TRAE Work，让它核对并重建任务。

Q：标签打错率一直偏高怎么办？
A：先检查关键词库是否过宽（如"技术"这类高频词会误伤）。建议：每个标签准备5-10个高区分度关键词，并把打错的3-5个样例发给TRAE Work，让它收紧规则并回归验证，一般迭代2-3次即可稳定。
